# 📸 오늘의 네컷: 교회 포토부스

태블릿 하나로 네 컷을 찍고, 4×6 인치 사진 한 장으로 저장하고 인쇄하는 무료 웹앱입니다.
처음 한 번만 인터넷으로 설치하면, **행사 당일에는 인터넷 없이** 사용할 수 있습니다.

## 🔗 앱 주소

### 👉 https://shepherdsdesk.github.io/photobooth/

- 소개 페이지: https://mokyangdesk.com/four-cuts.html
- 목양 데스크 홈페이지: https://mokyangdesk.com/

> 이 앱은 내려받아 설치하는 프로그램이 아니라 **주소로 여는 웹앱**입니다.
> 태블릿 브라우저에서 위 주소를 열고, 아래 1단계처럼 홈 화면에 추가해서 쓰세요.

---

## 1단계: 태블릿에 앱으로 설치하기 (인터넷 연결된 상태에서 1회)

**아이패드 (Safari)**
1. Safari로 **https://shepherdsdesk.github.io/photobooth/** 에 접속합니다.
2. 공유 버튼(□↑) → **홈 화면에 추가**를 누릅니다.
3. 홈 화면의 **네컷부스** 아이콘으로 실행하고, 카메라 권한을 **허용**합니다.

**갤럭시탭 (Chrome)**
1. Chrome으로 **https://shepherdsdesk.github.io/photobooth/** 에 접속합니다.
2. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
3. 아이콘으로 실행하고 카메라 권한을 **허용**합니다.

✅ 첫 화면 오른쪽 위에 **“✓ 오프라인 사용 가능”**이 보이면 준비가 끝난 것입니다.
👉 **행사 전에 꼭 확인하세요:** 비행기 모드로 바꾼 뒤 앱을 열어 촬영이 되는지 시험해 보세요.

> ⚠️ `index.html` 파일만 태블릿에 복사해서 열면 **카메라가 켜지지 않습니다.**
> 카메라는 보안상 `https://` 주소에서만 작동하므로, 반드시 위 주소로 접속해서 설치하세요.

## 2단계: 행사 당일 사용법

1. **⚙️ 설정**에서 아래 항목을 고릅니다. 고른 내용은 자동으로 저장되고, 오른쪽에서 실제 인쇄 모양을 미리 볼 수 있습니다.
   - 타이머 (3·5·8·10초)
   - 레이아웃
   - 프레임
   - 하단 문구 (행사명, 말씀 구절 등)
2. **📸 촬영 시작**을 누르면 카운트다운 후 4장을 연속으로 찍습니다.
3. 사진 확인 화면에서 마음에 안 드는 컷은 눌러서 **그 컷만 다시 찍을 수 있습니다.**
4. **✨ 완성하기**를 누른 뒤 **📥 사진 앱에 저장** 또는 **🖨️ 인쇄하기**를 누릅니다.

### 레이아웃
- **스트립 2줄** (추천): 4×6 한 장에 같은 사진이 두 줄로 나옵니다. 가운데를 잘라 **2명이 한 장씩** 가질 수 있습니다.
- **2×2 그리드**: 4×6 한 장 전체를 쓰는 큰 사진입니다.

## 📥 사진 앱 저장

| 기기 | 저장 방법 | 저장 위치 |
|---|---|---|
| 아이패드 | 저장 버튼 → 공유 창에서 **“이미지 저장”** | **사진 앱** (최근 항목) |
| 갤럭시탭 | 저장 버튼 → 자동 다운로드 | **갤러리 앱 → Download 앨범** |

> 아이패드에서는 보안 정책 때문에 웹앱이 사진 앱에 바로 저장할 수 없습니다.
> 그래서 매번 공유 창에서 **“이미지 저장”을 한 번 눌러야** 합니다. 이 방법이 웹에서 사진 앱으로 저장하는 유일한 공식 방법입니다.

## 🖨️ 인터넷 없이 인쇄하기

인쇄에는 인터넷이 필요 없습니다. **태블릿과 프린터가 같은 Wi-Fi에 연결되어 있기만 하면** 됩니다.

- **방법 A:** 인터넷이 안 되는 공유기라도, 태블릿과 프린터를 그 공유기의 같은 Wi-Fi에 연결하면 됩니다.
- **방법 B:** 프린터가 자체 Wi-Fi를 만드는 다이렉트 모드를 지원하면, 태블릿을 프린터 Wi-Fi에 바로 연결합니다. 캐논 셀피 등이 지원합니다.
- 프린터는 **AirPrint**(아이패드) 또는 **Mopria**(갤럭시탭)를 지원해야 합니다. 예: 캐논 SELPHY CP1500. 구매 전에 지원 여부를 꼭 확인하세요.

인쇄 창에서는 용지를 **4×6 (10×15cm)**, 여백을 **없음(테두리 없음)**으로 선택하세요.

> 아이패드에서 인쇄 버튼을 눌러도 창이 안 열리면, **📥 저장 버튼을 누른 뒤 공유 창의 “프린트”**를 사용하세요. 이 방법이 가장 확실합니다.

## 🖼️ 나만의 프레임 만들기 (JPG / PNG)

1. ⚙️ 설정에서 레이아웃을 먼저 고른 뒤 **“템플릿 받기”**를 누릅니다. 사진 칸 위치가 회색으로 표시된 가이드 이미지가 받아집니다.
2. 캔바(Canva), 미리캔버스, 파워포인트 등에서 템플릿과 **같은 크기**로 디자인합니다.
   - 스트립: **600 × 1800 px** (한 줄만 만들면 자동으로 두 줄로 복사됩니다)
   - 그리드: **1200 × 1800 px**
3. 설정에서 **이미지 선택**으로 프레임을 넣고, 적용 방식을 고릅니다.
   - **배경으로 깔기** (쉬움, 추천): 디자인 위에 사진이 자동으로 올라갑니다. JPG도 됩니다.
   - **사진 위에 덮기**: 사진 칸을 **투명하게 뚫은 PNG**로 만들어야 합니다. 스티커나 장식이 사진 위로 겹쳐 보이게 할 때 씁니다.
4. 프레임에 행사명을 이미 넣었다면, 설정에서 **“문구 표시”를 끄면** 됩니다.

프레임은 레이아웃마다 따로 저장되고, 태블릿 안에 보관되어 인터넷이 없어도 유지됩니다.

## 🛠️ 관리자용: 앱 수정·배포

- 앱 파일은 GitHub 저장소 **shepherdsdesk/photobooth**에 있고, GitHub Pages를 통해 위 주소로 배포됩니다.
- 파일을 고쳐서 다시 올릴 때는 `sw.js` 첫 줄의 `photobooth-v1`을 `photobooth-v2`처럼 **숫자를 하나 올려야** 태블릿에 새 버전이 반영됩니다.
  올린 뒤에는 인터넷이 연결된 상태에서 태블릿 앱을 한두 번 다시 열어 주세요.

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `sw.js` | 오프라인 실행용 (앱을 태블릿에 저장해 둠) |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | 홈 화면 앱 아이콘과 설정 |
